# 🌐 Meu Primeiro Olá Mundo em HTML

## 📝 Sobre o Projeto
Este repositório guarda uma relíquia da minha jornada na programação: o **primeiro código HTML que escrevi na vida** há alguns anos. 

Seguindo a tradição milenar dos desenvolvedores, comecei com o clássico **"Olá, Mundo!"** e aproveitei para testar meus primeiros parágrafos utilizando textos informativos (*Lorem Ipsum*). 

Hoje, este projeto serve como um marco inicial da minha história na tecnologia e um lembrete físico de onde tudo começou.

## 🚀 Tecnologias Utilizadas
* **HTML5**: Estruturação da página.

## 💻 Código Fonte Original
O projeto foi construído em um arquivo único com a seguinte estrutura:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>meu primeiro site em repostório</title>
</head>
<body>
   <h1>Olá, Mundo!</h1>
   <hr>
   <p>Lorem, ipsum dolor sit amet consectetur adipisicing elit. Eius reprehenderit, consectetur id quidem magnam nisi neque quam rerum rem minima odio architecto tenetur ea numquam ipsa nihil hic at tempore.</p>
   <p>Lorem ipsum, dolor sit amet consectetur adipisicing elit. Voluptates molestias recusandae voluptas nisi repellat adipisci ipsum architecto, facere quo distinctio, unde reprehenderit quae nihil vitae deserunt vel quisquam atque dolor.</p>
</body>
</html>
```

## 🛠️ Como Visualizar o Projeto
Não é necessário instalar nenhuma ferramenta ou servidor para rodar este projeto:

1. Faça o download ou clone este repositório.
2. Abra a pasta onde os arquivos foram salvos.
3. Dê um duplo clique no arquivo `index.html`.
4. O seu navegador de internet vai abrir a página automaticamente.
